# v0.1.0 architecture foundation

- Offline-first Python engine
- Deterministic VoiceTune configuration
- Acoustic-model protocol for local FastSpeech 2/TFLite integration
- Vocoder integration boundary
- Audio processing boundary for RNNoise/VAD
- CLI WAV generation with deterministic fallback
- Browser demonstration
- Android integration boundary
- CI, security checks, and tag-based release workflow

This release is an **architecture/SDK foundation**, not a claim that neural model weights are production-complete. Production quality requires trained and validated local model artifacts plus device benchmarks.
